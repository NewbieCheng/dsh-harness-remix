# 预设、项目指令与 Skill 隔离

> ✅ 领域实例：源码仓库可选案例 `docs/CASE-native-chat.md` 所列 OpenFilm preset 与注册器；单独安装不依赖该文件。配置字段在不同 DSH 版本可能变化；写入前检查当前插件 Config schema 和目标源码，不以本例断言所有版本适用。

## 职责

- Host 服务处理跨会话可复用能力、认证与数据；preset 决定一个 Agent 可用的 persona、指令链、工具和 skills。不要为了隔离一个领域会话而清空用户的全局 skill。
- persona 只放职责与关键约束；项目专属规则留在项目指令文件；大块参考、镜头库等通过工具或 skill 按需读取，控制常驻上下文。
- 创建会话时显式选择经验证的 preset，核实恢复会话的既有 preset；更新配置只保证新会话按新配置创建，不能声称已迁移旧会话。
- 若宿主支持配置默认根或注册专用 skill provider，使用受控根和允许列表，验证资源基目录、引用文件和工具目录，避免无关全局技能泄漏。配置不能取代工具和项目访问授权。
- 确认项目根标识和上层指令发现行为；项目中已有用户指令绝不覆盖。生成区更新须有明确所有权、版本及保留手写内容的策略。

## 验收

使用临时项目和模拟服务验证两套 preset 的 skill 与工具目录互不污染，已存在项目指令保留、缺少资源明确报错、重复加载能清理。真实 GUI 新会话、旧会话以及项目目录边界须在具备许可的环境独立验证；不要问真实模型作为自动化测试。
